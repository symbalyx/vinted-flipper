Vinted Flipper

Analyseur achat/revente Vinted — calcule la rentabilité, détecte les bonnes affaires, suit tes flips.

Python Achat/Revente Vinted Arbitrage

Principe

Trouver des articles sous-évalués sur Vinted, les revendre avec une marge après frais (commission Vinted 5% + 0.70€, protection acheteur 0.8%, port, emballage).

Marge mini

+30%

Confiance

0-100%

Profit net

Après frais

Installation

git clone https://github.com/symbalyx/vinted-flipper.git
cd vinted-flipper
python3 cli.py -h

Utilisation rapide

$ python3 cli.py analyze

Analyse interactive d'un article : colle le titre, le prix, l'état, la catégorie, la marque → reçoit la marge estimée et la recommandation.

$ python3 cli.py batch

Mode lot : colle plusieurs annonces d'un coup (titre | prix | état | catégorie | marque).

$ python3 cli.py stats

Statistiques de tous tes flips enregistrés : profit total, win rate, ROI.

Exemple

$ python3 cli.py batch
  [1] TRES BON FLIP | +18.48€ | +73.9% | Nike Air Force 1
  [2] SKIP          | -7.83€ | -65.2% | T-shirt Kiabi
  [3] FLIP EXCELLENT| +894€  | +111.8%| Sac Chanel

Comment çà marche

  1. Tu trouves un article sous-évalué sur Vinted
  2. Tu colles les infos dans cli.py analyze
  3. Le moteur estime le prix de revente, calcule les frais, la marge
  4. Il recommande : SKIP / SI BESOIN / BON FLIP / TRES BON FLIP / FLIP EXCELLENT
  5. Si tu achètes, tu enregistres le flip pour tracker ton profit réel

Flux de travail recommandé

1. Scanne Vinted (prix croissant) → trouve des marques à fort coefficient
2. Analyse avec cli.py → vérifie la marge estimée
3. Si BON FLIP et confiance > 50% → achète
4. Nettoie, photo, mets en vente à prix estimé
5. Enregistre le flip → stats s'améliorent
6. Les marques les plus rentables : Chanel, Hermès, LV, Moncler, Arc'teryx
