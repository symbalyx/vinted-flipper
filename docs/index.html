Vinted Flipper

Analyseur achat/revente Vinted — détecte les arnaques, calcule les marges, génère des annonces pro.

🔍 Analyse flip

Marge + recommandation

🚨 Détection arnaques

Score risque 0-100

📝 Annonces pro

Descriptions optimisées

📊 Tracking

Stats + historique

Installation

git clone https://github.com/symbalyx/vinted-flipper.git
cd vinted-flipper
python3 cli.py -h

Commandes

python3 cli.py analyze

Analyse interactive : colle le titre, prix, état → reçois la marge, le scan arnaque, et génère l'annonce.

python3 cli.py scam

Détecte les arnaques : entre le prix, la description, les infos vendeur → score de risque + alertes.

python3 cli.py generate

Génère une annonce professionnelle avec titre SEO, description détaillée, hashtags, et prix conseillé.

python3 cli.py batch

Mode lot : analyse plusieurs annonces d'un coup.

python3 cli.py stats

Statistiques : profit total, win rate, ROI, historique.

Détection d'arnaques

Analyse multi-facteurs :

  • ● Prix anormalement bas (luxe à 45€ = 🔴)
  • ● Phrases d'arnaque ("paiement hors Vinted", "contacte moi par SMS")
  • ● Nouveau vendeur sans avis
  • ● Photos issues d'internet
  • ● Compte très récent (< 7 jours)
  • ● Téléphone vérifié, photos réelles, bons avis = ✅

Génération d'annonces

Descriptions professionnelles selon la catégorie :

  • ✅ Titre optimisé SEO (marque + modèle + taille + mots-clés)
  • ✅ Description structurée (points forts, infos, mesures, défauts)
  • ✅ Prix conseillé (min / conseillé / max selon le segment)
  • ✅ Hashtags Vinted générés automatiquement
  • ✅ Templates par catégorie (sneakers, sac, veste, etc.)

Exemples

# Analyse + Scan arnaque + Annonce, tout en un :
$ python3 cli.py analyze
  Titre: Nike Air Force 1 blanches taille 42
  Prix: 25
  → PROFIT +9.48€ (BON FLIP)
  → SCAN: 🟢 Annonce saine
  → ANNONCE: description pro générée automatiquement

# Test arnaque :
$ python3 cli.py scam
  Titre: SAC CHANEL URGENT
  Prix: 45
  → 🔴 ARNAQUE PROBABLE (score 100/100)
  → 14 alertes : prix trop bas, contact hors plateforme,
    nouveau compte, photos internet...
